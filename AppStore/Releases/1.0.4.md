# Blip 1.0.4

Status: development draft; not submitted to App Store Connect. Final archive source and build will be recorded when the release is prepared.

## What's New — English

- Improved keyboard appearance and responsiveness.
- New keyboard themes, key sounds and haptic feedback.
- Try the keyboard and scanner directly inside Blip with the new test field.
- Share settings with another device by scanning a company-profile QR code with Blip.
- Improved keyboard and scanner stability.
- Fixed an issue that interrupted other audio when opening the scanner.
- Cleaner settings, an app-language shortcut and UI refinements.

## Neuigkeiten — Deutsch

- Verbesserte Tastaturdarstellung und schnellere Reaktionen auf Eingaben.
- Neue Tastaturdesigns, Tastentöne und haptisches Feedback.
- Tastatur und Scanner direkt in Blip mit dem neuen Testfeld ausprobieren.
- Einstellungen per Firmenprofil-QR-Code mit einem anderen Gerät teilen: einfach mit Blip scannen.
- Verbesserte Stabilität von Tastatur und Scanner.
- Ein Problem behoben, bei dem das Öffnen des Scanners andere Audiowiedergaben unterbrach.
- Übersichtlichere Einstellungen, eine Verknüpfung zur App-Sprache und verfeinerte Bedienoberfläche.
